Remote-Controlled System Using IR Sensors, Servos, and H-Bridge

Bluetooth Controlled Trace-Lining Robot

Tasked with a challenge of creating a robot that follows a line and finish a maze, I created several designs that considers several control system techniques, alongside both automated and wireless control.

One of the control systems I used was an H Bridge with a motor, where I had to consider the voltage and current ratings to efficiently drive the DC Motors. This was then implemented via Pluse Width Modulation (PWM) controls to vary speed with Duty Cycle variables. This was then replaced with Servos using 4 different functions depending on the variations of which IR sensor is turned on or off.

I also created an application that allows for the wireless control of the robot, where it uses the Bluetooth Module and respective buttons to control it in cardinal directions.

Cloud Storage Solution in Embedded Systems

ESP32 Camera Raspberry Pi Visual Capture Storage

After hearing a relative encounter a small car accident that warranted a benefit for footage along insurance, our family decided on acquiring an all in one dashcam. The idea was that it should be able to capture footage continuously while driving, where the footage recorded would then automatically be stored in an internal local drive, and when back home, the footage is added to cloud based storage. The footage can also be viewed real time in an application interface in mobile devices.

When researching existing product lineups, they were either priced highly, or are embedded in car systems. Additionally, no researched system allowed for seamless local and cloud based storage solutions. By using an ESP32 Camera Module, alongside a Raspberry Pi 4B, I was able to create a secure shell connection between the two, where the camera module records the footage whilst communicating with the Pi to stored locally securely. A web server then exists within an application to view that footage. The Pi then connects to the router through a Static IP for the footage to then automatically be stored in a secure database built through Apache Derby.

Responsive Design in Web Development

This Portfolio Website

This website is a project in itself. For my Year 13 Digital Technologies course, I designed and programmed my personal portfolio from scratch, starting with Figma wireframes and building mobile-first one page at a time with feedback from my stakeholders. I have kept improving it since.

Their feedback shaped many decisions: a full-screen sidebar with an animated burger icon, which I extended in JavaScript to lock scrolling and remember the scroll position, text that scales with clamp(), and a Fancybox gallery with hover zoom after a Lightbox library caused scrollbar issues. Storyboarding in Motion Graphics

Awards Ceremony Video Series for a Hobby Community

I edited three videos for an international hobby community's annual awards: a minor awards showcase, a group video category, and a top performers ranking. Working with a small production team, I spent around 55 hours on design and 85 hours on editing in early 2026.

Motion Design in Promotional Videos

Sports Hobby Animated Compilation

In my community, I received requests to compile a event videos, so I first created drafts for logos and themes, where I then developed low fidelity drafts into static graphic design storyboards.

Through my workflow, I drew out ideas on paper, then digitised them through Photoshop and Illustrator. I created vectorised assets that can then be animated through After Effects, where I would create the motion graphics.

The opening made use of adjustment layers such as gaussian blur, turbulent displace, grain, and fractal noise; reveals used wipes with camera controlled transitions to present text on ellipse paths in parallax and icons with wiggle expressions. The Round 2 opening used variables and parameters subtracted in an expression normalized for repulsion. This follows objects in sinusoid paths towards an opening transition that used parenting, track mattes and alpha blending.

Autonomous Navigation in Embedded Systems

Maze-Solving Robot Using PSoC and A* Pathfinding

For a university team project, my group of four built a robot that follows a projected black line maze, visits four checkpoints in order, and stops at its destination. I coordinated our meetings and documentation, and led the pathfinding side of the project.

To sense the 60Hz projector whilst ignoring 120Hz ambient light, we used a MATLAB Fast Fourier Transform to design a passive 50-100Hz bandpass filter for four phototransistors. We then iterated through six sensor layouts and four PCB revisions, driven by a PSoC controller.

I compared five algorithms in MATLAB (BFS, Dijkstra, DFS, Greedy Best First, and A*). A* guaranteed the shortest path whilst exploring only 42 nodes against 136 for BFS, so I helped integrate it with the robot, using encoder counts and sensors to confirm each junction before pivoting, with PID keeping it on the line.

Digital Systems Design in FPGA Hardware

Flappy Bird Game on an FPGA Using VHDL

For a university mini-project, my group of three built a complete real-time game in hardware: Flappy Bird on a Terasic DE0-CV board, played with a PS/2 mouse and displayed through VGA at 640x480 and 60Hz.

Written in VHDL as small modules wired at a structural top level, a PLL generates the 25MHz pixel clock and the game logic updates once per vertical sync. A four-state finite-state machine controls the menu, playing, paused, and game over screens, pipe gaps are randomised with a Galois LFSR, and collisions use bounding boxes. I used Python to convert artwork into palette-indexed bitmaps stored in on-chip memory through MIF files.

We replaced DIP switch mode selection with mouse-driven menus, and scaled difficulty with pipes passed instead of time. The final design used only 5% of the logic elements, with the pixel clock closing timing at 69.78MHz against the 25MHz required.
